# ListsTurner

## 总览

ListsTurner是一个可以同步你网易云音乐和YoutubeMusic歌单的工具。


## 发布

提供Windows版和Android版，其他平台请自行打包。

不定期发布新版本，以接入更多的音乐平台，并保持平台接口的可用性。


## 跟进项目

项目的Win端和Android端现已达到高完成度，正在进行功能优化。


## 使用

网易云音乐：可以通过扫码登录，或手动导入cookie。

YoutubeMusic：可通过网页轻松登录，或通过谷歌开发者工具读取你的数据。

若你有在YoutubeMusic和任意国内音乐平台有同步歌单的需要，皆可使用此工具。

例如，若要将QQ音乐的歌单同步到YoutubeMusic，你可以使用网易云音乐的官方歌单导入功能，先将QQ音乐的歌单导入到网易云音乐，再使用ListsTurner导入到YoutubeMusic。


## 注意

此工具没有云端保存数据功能，因此若你需要保留你的同步记录，请使用工具的数据导出功能（此功能亦有自动导出模式）。

若你对同步记录不满意，可以使用回滚功能（需要拥有同步记录）。


## 额外注意

此工具为氛围编程产物，基于个人学习的目的开发，若有问题请包涵。


# 详细说明

## 1-功能细节

在平台登录完成的转换工作中，你可自由选择单端同步或双端同步。

同步前，你亦可自由选择同步歌曲，支持快捷搜索。

你可自由选择同步是否生成记录。


## 2-软件界面

支持八大语种。

支持界面缩放。

支持自定义字体。

支持深浅色自动切换。

支持自定义文字。

支持多种主题选择。

支持对悬浮底栏进行修改（仅Android）。

…


## 3-数据存储

你在ListsTurner产生的数据只会保留在本地。
